# Runtime and development dependencies.
#
# Direct dependencies only, grouped and commented so the intent is readable.
# The transitively pinned set lives in requirements.lock.txt, which is what CI
# installs. Pinning only direct dependencies does not make a run reproducible,
# so the lockfile is the one that matters and this file is the one humans read.
#
# Versions are pinned rather than floated, because a benchmark result that
# cannot be reproduced on the same dependency set is not a result.
#
# Regenerate the lock after editing this file:
#   uv pip compile requirements.txt -o requirements.lock.txt
#
# Deliberately absent until the slice that needs them, so that nothing
# speculative is installed:
#   tiktoken                  the limiter is not built, and tiktoken downloads
#                             BPE files from the network on first use, which
#                             would make CI flaky
#   openai, anthropic         no real provider adapters yet
#   chromadb,                 Tier 2
#   sentence-transformers
#   opentelemetry-*           observability phase
#   ragas                     evaluation phase
#   locust                    load testing phase
